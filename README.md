# 🚀 Portfolio — Cemil SERTTAS

Portfolio personnel construit avec HTML, CSS et JavaScript vanilla.  
Design inspiré du template **Profiler** avec des animations de motion design.

## ✨ Fonctionnalités

- 🎨 Design sombre premium avec palette verte/dorée
- ⚡ Animations de scroll (reveal, stagger, counters)
- 🖱️ Effets interactifs (cursor glow, tilt cards, magnetic buttons)
- 📱 Entièrement responsive
- 🔤 Typographie mixte Inter + Instrument Serif
- 📊 Barre de progression de scroll
- 🏷️ Navigation flottante avec section active

## 📂 Structure

```

├── script.js       # Animations et interactions JS
├── assets/
│   └── profile.jpg # Photo de profil

└── README.md
```

## 🚀 Déploiement sur GitHub Pages

1. Créer un nouveau repository sur GitHub
2. Pousser les fichiers :
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio"
   git branch -M main
   git remote add origin https://github.com/VOTRE_USERNAME/VOTRE_REPO.git
   git push -u origin main
   ```
3. Aller dans **Settings > Pages**
4. Source : **Deploy from a branch** → `main` / `/ (root)`
5. Sauvegarder → le site sera en ligne !

## 📝 Personnalisation

Modifier directement les fichiers HTML pour mettre à jour :
- Vos informations personnelles dans `index.html`
- Les couleurs dans les variables CSS de `styles.css`
- Remplacer `assets/profile.jpg` par votre propre photo
